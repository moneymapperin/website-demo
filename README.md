# MoneyMapper

Static UI clone of the MoneyMapper Flutter finance app (React + Vite + Tailwind).

## Run

```bash
npm install
npm run dev
```

Opens on `/dashboard` with mock data. No auth or API required.

## Stack

- React (Vite)
- React Router
- Tailwind CSS v4
- Recharts

## Notes

- Dark mode toggle persists in `localStorage`
- All data lives in `src/mockData/`
- Auth screens are UI-only; reach them via sidebar “Auth Screens (Preview)” or direct URLs
